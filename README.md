# Quest2RareScanner

[中文](README.md) | [English](README.en.md)

把 Questie 里的任务目标快速加入 RareScanner 追踪，适合寻找：

- 会移动的任务物品掉落怪
- 会移动的任务交付 NPC
- 有多个刷新点的任务目标

插件**不会自动添加数据**。什么时候加、加哪一只，由你决定。添加后 RareScanner 负责靠近报警，插件负责在任务状态变化后自动移除过期追踪。

## 主要功能

### 世界地图：Alt + 左键

打开世界地图，按住 `Alt` 左键点击 Questie 图标：

| 图标 | 加入 RareScanner |
|---|---|
| 击杀 / 掉落图标 | 对应的任务怪 |
| 任务给予图标 | 任务给予者 |
| 任务交付图标 | 任务交付 NPC |
| 物品起始任务图标 | 掉落起始物品的 NPC |
| 手动标记 NPC | 该 NPC |
| 地面物件 / 事件 / 小地图图标 | 不支持 |

- 会写入该 NPC 的全部刷新点和巡逻路径
- 巡逻目标显示“巡逻 N 条路径”
- 多刷新点目标显示“已知 N 个刷新地点”
- 固定单点不额外显示位置标签

### 任务日志：骷髅按钮

打开任务日志（L），选中一个已接受的任务，右侧详情面板右上角会出现 RareScanner 骷髅按钮。

- **任务进行中**：可选择“击杀 / 掉落目标”和“任务交付”
- **任务可交付**：只显示“任务交付”
- 每只怪单独勾选，可以只追踪其中一只
- 默认全选；列表超出可视区域时才显示右侧滚动条

### 自动移除

| 任务状态 | 插件行为 |
|---|---|
| 接受任务 | 移除任务给予者的追踪 |
| 任务可交付 | 移除击杀 / 掉落目标，保留任务交付 NPC |
| 任务交付 / 放弃 | 移除该任务的全部追踪 |
| 物品起始任务接取后 | 移除起始物品掉落怪 |

- 战斗中的变化会延后到脱离战斗后处理
- 重新登录或重载后会按当前任务状态补做
- 已经内置在 RareScanner 的 NPC 不会被重复添加

### 小地图按钮

- Questie 任务图标 + RareScanner 骷髅角标
- **左键**：删除插件添加的全部追踪
- **右键**：帮助 / 状态
- **拖动**：调整位置

## 依赖关系

| 插件 | 作用 | 必需 |
|---|---|---|
| Questie | 地图图标、任务目标、刷新点、巡逻路径、ZoneDB | 是 |
| QuestieDB | LibQuestieDB：NPC、任务、物品数据 | 是 |
| RareScanner | 自定义 NPC 导入/删除、靠近报警 | 是 |

TOC 已用 `## RequiredDeps` 声明。缺少任意一个依赖时，游戏会提示依赖缺失，插件不会加载。

## 安装

需要先安装：

- Questie
- QuestieDB
- RareScanner

下载 Release 里的 `Quest2RareScanner-<版本>.zip`，解压到：

```text
World of Warcraft/_forever_/Interface/AddOns/
```

确保路径是：

```text
.../AddOns/Quest2RareScanner/Quest2RareScanner.toc
```

然后 `/reload`。

## 使用步骤

1. 打开世界地图，找到 Questie 图标。
2. 按住 `Alt`，左键点击图标。
3. 查看聊天报告：会列出加入了哪些 NPC，以及位置类型。
4. 靠近目标时，RareScanner 会弹窗并播放声音。
5. 任务状态变化后，插件会自动移除不再需要的目标。

任务日志入口：

1. 打开任务日志，选中已接受的任务。
2. 点右侧详情面板右上角的骷髅按钮。
3. 勾选需要的击杀 / 掉落目标或任务交付 NPC。
4. 点“加入”。

## 排错命令

日常使用不需要命令；以下命令只用于排错：

```text
/q2rs          显示状态
/q2rs delete   删除插件添加的全部追踪（等同小地图按钮左键）
/q2rs debug    输出当前任务和追踪数据
```

## 常见问题

**为什么点击图标没反应？**  
可能是地面物件 / 事件图标，RareScanner 不支持自定义物件；也可能是 Questie 没有这个 NPC 的数据。

**为什么提示“已包含”？**  
这个 NPC 已经在 RareScanner 内置库里，不需要再作为自定义 NPC 添加。检查 RareScanner 的 NPC 过滤器和扫描设置即可。

**为什么删除后地图上还有图标？**  
可能是 RareScanner 的“最近目击”标记，最多保留 2 分钟（副本 30 分钟）；也可能那是游戏自带的稀有图标，不受插件控制。

**支持哪些客户端？**  
只支持魔兽世界无限（WoW Forever）1.60.1。
